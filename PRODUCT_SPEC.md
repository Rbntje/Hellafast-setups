# HELLAFAST SETUPS

Find Your Line. Build Your Setup. Chase Perfection.

HELLAFAST is an iPhone-first, local-first race engineer for EA SPORTS F1 25. Players select a circuit and conditions, confirm driving preferences, review source evidence, generate a candidate setup and iterate in a private garage. Numerical advice is a starting point for in-game testing.

| Section | Main job |
| --- | --- |
| Home | Resume work, see recent and favorite setups, inspect engine readiness |
| Create setup | Select conditions, confirm Driver DNA, review evidence and generate |
| My Garage | Organize, edit, export and compare complete version histories |
| AI Engineer | Work on an active setup, explain changes and propose adjustments |
| Profile | Edit Driver DNA, manage local storage and backups, inspect model support |

The initial supported configuration is generic F1 25 base-game handling. The 2026 Season Pack needs its own verified setup schema. The setup workflow always requires quiz confirmation. Community data and calculated adjustments retain provenance. Setup creation and version edits must remain available offline after the app shell is cached. Private data stays in IndexedDB.

Acceptance for the first usable release requires a reproducible build, a real browser test of the main setup flow, valid values across supported conditions, safe backup import, and offline reload on a project URL.
