# Project status

## Implemented in the initial preview

- Five navigation sections and original ignition, with skip, abbreviated return and reduced-motion paths.
- Persistent adaptive quiz, 24 base-game circuit profiles and 20 range-checked settings.
- Optional browser research from a pinned public aggregate, manual source entry, real worker stages and offline fallback.
- On-device Garage with subfolders, search, tags, favorites, archive, bulk archive and export, duplication, and metadata autosave.
- Version history with manual and engineer adjustments, exact comparison, restoration and structured test feedback.
- Local Driver DNA, local engineer conversations, JSON and ZIP backups, validated merging, and duplicate ID detection.
- Static offline app shell, Capacitor iOS project and GitHub Pages deployment workflow.
- Opt-in SmolLM2 request interpretation with download progress, removal and deterministic fallback.

## Pending verification and development

Setting ranges are corroborated by community references. The preview labels generated setups Experimental when relevant settings lack verified session, patch and car provenance. F1 25 car-specific balance, the 2026 Season Pack, and richer source coverage remain pending. The small language model handles request interpretation and needs device and accuracy benchmarks. The native project and the installed Home Screen PWA still need physical testing. GitHub Pages requires repository-level activation before deployment can complete.
