# Development roadmap

1. Record product and feasibility decisions. Verify platform, community data and deployment sources.
2. Build the navigation shell, design tokens and ignition. Review desktop and compact layouts.
3. Implement the versioned setup schema, confirmation quiz, offline calculation and source-aware worker.
4. Integrate the garage, comparisons, Driver DNA, engineer adjustments and backup recovery. Inspect empty, loading and failure states.
5. Test production assets on a GitHub project path. Exercise offline activation and reload, then publish the preview.
6. Validate supported ranges on the actual game. Expand session-specific source coverage, track and car data, and verify the separate Season Pack schema.
7. Benchmark small local models on supported iPhones and implement consent-based model management for a verified runtime. Validate the installed PWA and Capacitor build on Apple hardware.
