# Design system

HELLAFAST uses deep black (#0b0d0b), graphite (#141714), warm white (#f2f4ee), muted silver (#a6aca0) and acid green (#d9ff42). Red is reserved for errors and destructive actions. A wide display face in italic carries the motorsport identity. Interface type uses a locally bundled sans serif. Uppercase monospaced labels identify technical data.

The desktop layout pairs a fixed-width navigation rail with a broad working area. The mobile layout uses five safe-area-aware bottom destinations. A single dominant action anchors each screen. Setup results use aligned setting rows, grouped by how the user enters them in the game. Quiz selections appear as full-width rows with a visible selected state.

The original ignition draws a single telemetry-inspired stroke into an angular mark. The first run includes a Skip button. Returning sessions use abbreviated motion, and reduced-motion sessions enter directly. Layouts support 44 px touch targets, keyboard focus, readable contrast, large text, and scrolling inside the active viewport.
